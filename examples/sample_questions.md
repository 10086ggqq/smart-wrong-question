# 数学错题集（示例数据，非真实学生记录）

> 不代表任何真实学生的学习记录。分析结果仅用于验证 Skill 功能。

## Q001
题干：已知函数 $f(x) = x^3 - 3x$，求函数的极值。
标准答案：求导得 $f'(x) = 3x^2 - 3$，令 $f'(x) = 0$ 得 $x = \pm 1$。当 $x < -1$ 时 $f'(x) > 0$，当 $-1 < x < 1$ 时 $f'(x) < 0$，故 $x = -1$ 处取得极大值 $f(-1) = 2$；同理 $x = 1$ 处取得极小值 $f(1) = -2$。
学生答案：极大值为 2，极小值为 -2。
学生解题过程：求导得 $f'(x) = 3x^2 - 3$，令 $f'(x) = 0$，解得 $x = \pm 1$，代入原函数得极大值 2、极小值 -2。
学生自评：不知道哪里错了，答案看起来是对的。

## Q002
题干：判断函数 $f(x) = x^2 + 1$ 的奇偶性。
标准答案：定义域为 $\mathbb{R}$，关于原点对称；$f(-x) = (-x)^2 + 1 = x^2 + 1 = f(x)$，故 $f(x)$ 为偶函数。
学生答案：$f(-x) = -f(x)$，所以是奇函数。
学生解题过程：把 $-x$ 代入得 $x^2 + 1$，然后直接写了奇函数。

## Q003
题干：已知等差数列 $\{a_n\}$ 中，$a_1 = 2$，$a_3 = 8$，求通项公式 $a_n$。
标准答案：设公差为 $d$，$a_3 = a_1 + 2d = 8$，解得 $d = 3$，故 $a_n = 2 + (n-1) \times 3 = 3n - 1$。
学生答案：$a_n = 3n + 2$。
学生解题过程：算出 $d = 3$ 之后，直接写成 $a_n = 3n + 2$。
学生自评：公差求对了，最后通项写错。

## Q004
题干：函数 $f(x) = \ln(x^2 - 3x + 2)$ 的定义域是什么？
标准答案：令 $x^2 - 3x + 2 > 0$，解得 $x < 1$ 或 $x > 2$，定义域为 $(-\infty, 1) \cup (2, +\infty)$。
学生答案：$x < 1$ 或 $x > 2$。
学生解题过程：对数里面要大于 0，解了一元二次不等式。

## Q005
题干：利用导数求函数 $f(x) = x^3 - 3x$ 在区间 $[-2, 2]$ 上的最大值与最小值。
标准答案：$f'(x) = 3x^2 - 3 = 0$ 得 $x = \pm 1$。计算得 $f(-2) = -2$，$f(-1) = 2$，$f(1) = -2$，$f(2) = 2$。比较得最大值为 2，最小值为 -2。
学生答案：（无）
学生解题过程：（无）
备注：学生只抄录了题目，未提供作答内容。

## Q006
题干：求 $\sin 30^\circ + \cos 60^\circ$ 的值。
标准答案：$\sin 30^\circ = \frac{1}{2}$，$\cos 60^\circ = \frac{1}{2}$，和为 1。
学生答案：$\frac{\sqrt{3}}{2}$。
学生解题过程：记错公式，把 $\cos 60^\circ$ 当成了 $\frac{\sqrt{3}}{2}$。
